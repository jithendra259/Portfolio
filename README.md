# Portfolio Project

This repository contains a **frontend** built with Next.js and a **backend** Python service.

## Deploy to Vercel

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/import/project?repo=https%3A%2F%2Fgithub.com%2Fjithendra259%2FPortfolio)

The button will import the monorepo and use the `vercel.json` at the repository root to deploy both the frontend and backend.

## Project structure

- `frontend/` – Next.js application
- `backend/` – Python API (FastAPI/Flask)
- `vercel.json` – Vercel configuration for the monorepo
