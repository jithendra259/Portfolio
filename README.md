# Jithendra's Portfolio - Next.js Frontend

The interactive React / Next.js web application for Kandula Jithendra Subramanyam's personal portfolio.

## 🚀 Features

- **Interactive Voice Agent**: Real-time WebRTC audio connection to the LiveKit voice agent running on Render.
- **Deepgram STT & Cartesia TTS**: High-speed speech-to-text and low-latency voice responses.
- **Autonomous Auto-Navigation**: The voice assistant programmatically highlights and navigates to sections (Experience, Projects, Education, Research Papers) in sync with conversation context.
- **Interactive Research Showcases**: Detailed empirical tables, equations, and figures for 3 quantitative financial research papers.
- **Dynamic Audio Visualizers**: Audio visualizer bar/wave components for natural voice feedback.

## 🛠️ Local Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚢 Deployment

Configured for one-click deployment on **Vercel** via the `frontend` branch.
